## Employee Database Management System

The Employee Database Management System is a comprehensive web application designed to streamline and automate the management of employee information within an organization. This system facilitates efficient handling of employee data, from initial registration to profile updates, ensuring data integrity and accessibility.

## Features

1. Employee Registration: New employees can register by providing essential details such as Employee ID, Name, Email, Designation, Phone, and Profile Image. The registration process is user-friendly, with form validation to ensure accurate data entry.

2. Profile Update: Employees can update their personal information, including Full Name, Address, Phone Number, and Profile Photo, ensuring that the database reflects current details.

3. Success Confirmation: Upon successful registration or profile update, the system displays a confirmation page with relevant information and navigation options, enhancing user experience.

4. Employee Code of Conduct: The system provides a section outlining the organization's code of conduct, ensuring that employees are aware of company policies and expectations.

## Technologies Used

1. Frontend: The user interface is built using HTML5, CSS3, and Bootstrap 5, providing a responsive and visually appealing design.

2. Backend: The system is powered by ,Java with SpringBoot, JavaScript for form handling and validation.

3. Styling: Custom CSS is utilized to enhance the aesthetic appeal and user experience of the application.

## Project Structure

1. index.html: Employee Registration page with a form for new employees to submit their details.

2. success.html: Confirmation page displayed after successful registration, providing navigation options to the login page or dashboard.

3. profile_update.html: Page allowing employees to update their personal information and profile photo.

4. css/style.css: Custom CSS file containing styles for the profile update page.

5. js/profile.js: JavaScript file handling form submission and client-side validation for the profile update page.

## Setup and Usage

1. Clone the Repository: Clone the repository to your local machine using git clone.

2. Navigate to the Project Directory: Use cd to navigate to the project directory.

3. Open in Browser: Open index.html in your preferred web browser to start the application.

4. Register a New Employee: Fill out the registration form and submit to add a new employee.

5. Update Profile: Navigate to profile_update.html to update employee information.
